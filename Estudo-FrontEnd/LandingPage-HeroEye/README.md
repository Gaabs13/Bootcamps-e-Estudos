**Link da Demonstração na prática:** [landing-page-hero-eye.vercel.app](https://landing-page-hero-eye.vercel.app/)

Este repositório apresenta decisões de interface e trechos selecionados de uma aplicação de portfólio de fotografia e filme. 
A experiência combina duas direções visuais — urbana e natural — com conteúdo em português, inglês e espanhol.

O material aqui é intencionalmente demonstrativo: contém explicações e exemplos pequenos para leitura técnica, não o código integral da aplicação, seus dados, mídias ou configuração de produção. 
Os exemplos foram reduzidos para ilustrar os padrões descritos e não formam, isoladamente, uma aplicação executável.

## O que este estudo apresenta

Como o estado de modo visual seleciona temas e coleções de conteúdo.
Como cada hero cria uma interação visual diferente a partir do movimento do ponteiro.
Como textos tipados e controles acessíveis sustentam três idiomas.
Como cor, composição editorial, sessões e galerias formam uma linguagem visual consistente.

## Sobre o código demonstrativo

Os exemplos isolam conceitos, usam nomes de domínio genéricos quando isso melhora a leitura e omitem detalhes de implementação que não são necessários para explicar a ideia. Não incluem ativos, conteúdo integral, estrutura de navegação completa ou código suficiente para reconstruir a aplicação.

Esta curadoria serve para contextualizar o trabalho, não como barreira técnica de acesso ou proteção contra cópia.
