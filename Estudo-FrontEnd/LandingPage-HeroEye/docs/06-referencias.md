# Referências e escopo

## Projeto apresentado

- Aplicação online: [landing-page-hero-eye.vercel.app](https://landing-page-hero-eye.vercel.app/)
- Direção de arte original indicada pelo projeto: [Landing Page for Photography no Figma](https://www.figma.com/design/HZ0XEk1it4VxMOIg0hF9HB/Landing-Page-for-Photography)
- Tecnologias observadas na aplicação: React, TypeScript, Vite, Tailwind CSS e Motion.

## Como ler os exemplos

Os exemplos deste repositório são resumos pedagógicos inspirados nas responsabilidades e nos padrões da implementação apresentada. Eles foram reduzidos e reorganizados; não são cópias integrais dos componentes de produção, e podem omitir detalhes necessários para executá-los isoladamente.

Para preservar esse escopo, este repositório não inclui a aplicação completa, os arquivos de mídia, dados integrais dos projetos, dependências, credenciais ou configuração de deploy.

## Mídia e atribuição

A aplicação pode apresentar conteúdo de exemplo e referências de mídia hospedadas por provedores externos. Consulte os termos e as licenças de cada autor ou serviço antes de reutilizar mídia, marcas ou elementos visuais.

## Publicação e reutilização

O link da aplicação é público e qualquer pessoa pode consultá-lo. A curadoria de explicações reduz o material publicado, mas não impede cópia de ideias ou reimplementação. Nenhuma licença de reutilização foi escolhida para esta apresentação.
