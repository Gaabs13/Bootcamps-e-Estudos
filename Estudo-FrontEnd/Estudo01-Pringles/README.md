Projeto de estudo e experimentação em desenvolvimento front-end focado na criação de uma **landing page interativa e animada**, com transições dinâmicas, microinterações e exploração de animações avançadas no navegador.


Este projeto simula uma landing page de produto com foco em experiência visual e interação do usuário, explorando técnicas modernas de front-end para construção de interfaces ricas e dinâmicas.

A proposta é transformar uma página estática em uma experiência imersiva, utilizando animações, transições de slides e elementos visuais interativos.


## 🤝 Colaboração

Projeto desenvolvido em colaboração com Gustavo (@devart), durante uma sessão ao vivo de desenvolvimento front-end, com foco em construção de interfaces interativas e animações no navegador.


 🧠 Conceitos aplicados:

Manipulação de DOM; <br>
Estruturação de layout com HTML semântico; <br>
Estilização avançada com CSS; <br>
Controle de estado de slides (carrossel); <br>
Animações e transições com JavaScript; <br>
SVGs e elementos vetoriais animados; <br>



## ⚙️ Stack utilizada

HTML5 <br>
CSS3 <br>
JavaScript (ES6+) <br>
GSAP (GreenSock Animation Platform) <br>
ScrollTrigger <br>
SplitType <br>
SVG Animation <br>


## 🎞️ Funcionalidades e Estrutura do projeto

Slider interativo com troca de sabores; <br>
Navegação entre slides com botões e indicadores; <br>
Elementos animados e responsivos; <br>
Animações de entrada e transição de conteúdo; <br>
Seções com efeitos visuais e SVG dinâmico; <br>
Layout inspirado em landing pages de produto; <br>

Header com navegação e menu interativo;
Seção de slides principal (carousel de produtos);
Seção com animações SVG e efeito marquee;
Seções de destaque com storytelling visual;
Footer com destaque de produto;
